One Sentence for a Traveler from 1800: a single sentence explaining the modern internet to someone from 1800, built only from things they already know — every post office, library, and market stall in the world joined by one road, where any letter you send arrives before the ink dries. The program writes the sentence to `/output/entry.txt` — 141 characters in total (limit 200).

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt`.
